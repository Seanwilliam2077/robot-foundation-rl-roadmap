# Robot Foundation RL Roadmap

通用机器人基础模型、物理学习与强化学习的研究路线图。

**[查看完整中文 TODO →](docs/ROBOT_FOUNDATION_RL_TODO_ZH.md)**

以 NVIDIA Isaac GR00T、Isaac Lab 和 PhysicsNeMo 为主要组件，建立可复用的多任务、多机器人实验平台。

## 研究路线

- 冻结 GR00T 基础策略，训练受约束的 Residual RL 策略。
- 用 PhysicsNeMo 学习执行器响应与局部动力学，评估模型辅助 RL。
- 通过 Isaac Lab + RLinf 探索直接 VLA 后训练，并进行统一预算下的对照。
- 分别验证新物体、新场景、新动力学和新机器人的泛化，以及真实机器人迁移。

## 路线图

| 阶段 | 交付重点 |
| --- | --- |
| M0 | 可复现环境、版本与资源基准 |
| M1 | 机器人、动作、观测和时序接口 |
| M2 | 多任务数据、基线与评估协议 |
| M3 | GR00T 基础策略接入 |
| M4 | PhysicsNeMo 局部物理模型 |

| M7 | 泛化、真实数据与复用验证 |
